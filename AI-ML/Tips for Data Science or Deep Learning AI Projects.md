## Data Exploration
- Missing Values:
	- The threshold for **missing values** in order to perform imputation or fill the missing value is **30% up to 40%** from the dataset values. 
	- If we have more than 70% - 80% missing values in our dataset, it's better for us to drop them. 
	- To impute missing values, we also have to pay attention to the data summary, because somehow we can interpret some missing values columns as a certain category.
