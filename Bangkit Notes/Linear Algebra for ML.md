## System of Equations
**Linear Regression** ⇒ Machine learning approache that takes many input in order to predict the output 
Goal ⇒ To find the line that fit the best to the pattern of data point

For an example:
![[wind_bind1.PNG]]
-> Suppose we want to predict the electrical output from an wind turbine. 
In this case, we have an input or feature that is the wind speed and output or target that is power that is generated by the turbine. 

![[linear_reg1.PNG]]
Look at picture above
	We have one feature that is wind speed. So in this case, we show wind speed as an x-axis and power output as a y-axis. The data point represents the measurements of wind speed and power output
	If we know the wind speed then we do this : 
	=> m * windspeed + b -> To estimate the result of power output 

The equation of Linear Regression depends on how many features that we consider. 
So in general:
$$w_1x_1 + w_2x_2\:+ ... +\:w_nx_n = y$$
Since we have many records of data if reality, We can write down of linear equations for each records of dataset
![[linear_reg2.PNG]]
Bias :  Error between average model prediction and the ground truth. In machine learning, the linear regression model isn't perfect. If you see the line, there are some data point the that aren't in the line. So that is bias

Weight : Real values that are attached with each input/feature and they convey the importance of that corresponding feature in predicting the final output.

Example: 
	
	![[linear_reg_3.PNG]]
	In the picture above, there's a set of scoring from a course. But, we yet don't know about our actual score. We could represent those sentece as system of linear equations. We could represent Linear algebra as 'a', Calculus as 'c', and Probability as 'p'. 
	If we turn the sentences to some linear equations, it would be:
	a + c - p   = 6
	a - c + 2p = 4
	4a - 2c + p = 10
	` `
	From that, we can conclude that:
	- Weights : a, c, p -> Consistent across all the statement
	- Features : The coefficient that stand next to the weight
	- Target : The number after the equal sign
